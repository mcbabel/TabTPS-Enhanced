## New

- **Settings menu in the game:** `/tabtps` or `/tabtps gui` changes the displays, modules, themes, custom text, lag alerts and general options and writes them to the config files. On Minecraft 1.21.6 and newer it uses dialog screens that switch pages smoothly without asking to confirm a command, on older versions a chest menu. The chest menu shows your TPS and MSPT live and can play sounds (`menu-sounds`, off by default). `gui-style` picks the dialog or the chest menu. Works on the plugin and the Forge mod, permission `tabtps.gui`
- **Region overview** on Folia and Canvas: `/tabtps regions` lists the busiest regions with world, center, TPS, MSPT, utilisation, chunks, players and entities. Click a line to teleport there (`tabtps.regions.teleport`)
- **Lag alerts:** a chat message, a console line and optionally a Discord message when the server stays below a TPS or above an MSPT limit. The alert names the busiest region. Off by default, turn it on with `enabled=true` in the `lag-alerts` section of `main.conf`
- **Velocity plugin:** `/networktps` (alias `/ntps`) shows the TPS, MSPT and players of all backend servers on the proxy. Backends send their values with `send-stats-to-proxy=true`
- **MiniPlaceholders:** the placeholders are also available as MiniMessage tags like `<tabtps_tps>`, when MiniPlaceholders 2.x or 3.x is installed
- Modules that cannot work on a server, like the region modules without regions or mob caps on Folia, are left out instead of showing N/A
- The project is now called **TabTPS Enhanced** (formerly TabTPS Folia). The plugin jar is now `tabtps-enhanced-<version>.jar`; plugin name, config folder and download links stay the same
- The update checker uses the permanent Modrinth project ID

All new options are off by default.

**When updating the plugin, delete the old `tabtps-folia-*.jar`** from the `plugins` folder, otherwise the server finds two plugins called TabTPS.
